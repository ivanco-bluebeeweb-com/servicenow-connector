# ServiceNow Connector — идеальный первый запуск

Источник: `ONBOARDING_FIRST_LAUNCH_STANDARD.md`. Целевой пользователь: агент service
desk, ITSM-администратор или ops-инженер, впервые открывающий приложение.

## 1. Credential type
Instance hostname (`<instance>.service-now.com`) + один из двух режимов: OAuth2
(client id/secret) или Basic Auth (integration user username/password).

## 2. Идеальный флоу (без ограничений SDK)
1. **Явный выбор режима подключения** — переключатель "OAuth2" / "Basic Auth" перед
   формой, так как поля принципиально разные, а не универсальная форма со всеми полями
   сразу (которая запутает пользователя, не понимающего, что нужно заполнить).
2. **Проверка инстанса перед сохранением** — реальный запрос к Table API (например,
   `sys_user` с limit=1) чтобы подтвердить и хост, и креды разом, а не просто сохранить
   введённые данные.
3. **После успеха — сразу health snapshot** — количество открытых инцидентов по
   приоритету, чтобы пользователь сразу увидел, что подключение реально работает и
   видит live-данные, а не просто прошло аутентификацию.
4. **Явное объяснение generic passthrough** — при первом открытии кратко пояснить, что
   помимо готовых Incident/Problem/Change/Request экранов есть универсальный доступ к
   любой другой таблице инстанса (для кастомных таблиц клиента) — не как отдельная
   скрытая функция, а как явно показанная возможность.
5. **Ошибки аутентификации — понятные, не generic 401** — например, если OAuth
   client неверно сконфигурирован в самом ServiceNow (Application Registry), явно
   подсказать проверить настройки OAuth-эндпоинта в инстансе, а не просто "unauthorized".
6. **Multi-instance** — переключатель между несколькими подключёнными инстансами
   (dev/test/prod), с явным лейблом на каждом.

## 3. Разница с реализацией сейчас
См. `UI_COMPONENT_PLAN.md` §0 — реализация ограничена наличными примитивами SDK
(`ui.Select` для переключения режима подключения работает через `on_change` + условный
рендеринг полей формы, а не динамическое скрытие/показ полей внутри одной формы).
